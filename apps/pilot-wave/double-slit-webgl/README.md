# Double Slit — Numerical (WebGL2)

Published standalone entry for the numerical notebook's existing WebGL2 applet.
The entry redirects to `notebooks/double-slit-webgl/full-applet.html` without
`embed=1`, so the full standalone controls remain available. Query presets and
URL fragments are retained. There is one simulation engine, not a copied fork.
The separate older app remains in `archive/double-slit-numerical/`.
