# Archived standalone numerical double-slit app

Archived at the project owner's request on 8 November 2026. This older standalone
implementation is no longer listed as a current teaching resource. Its source,
figures, Python and MATLAB reference code, and original metadata are preserved.
Only archive labels and the shared-asset paths in index.html have changed.

The original URL, `apps/pilot-wave/double-slit-numerical/`, is retained as an
archive notice linking here and to the current notebooks. The numerical notebook
at `notebooks/double-slit-webgl/` has its own main.js and shaders and does not
import this app. Both the numerical and analytical notebooks remain published.
Double Slit 2.0 and the original comparison copies are unchanged.
